## Issues from previous note

- Testing generators remains unresolved, deferring until after arrays coverage

----

I am thinking of testing generators by exhausting them into arrays and comparing those arrays to expected results. This means the test runner should be slightly modified to check the evaluated code not only for functions or values, but also for generators.

```js
function* sumUpTo(number) {
  for (let i = 1; i <= number; i = i + 1) {
    yield i;
  }
}
```

This should be tested such that calling `sumUpTo(3)` and exhausting it produces `[1, 2, 3]`.
