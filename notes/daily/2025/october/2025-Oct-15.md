## On generators and testing them

Current testing framework assumes two types of code snippets: functions and expressions. Generators are neither, so we need to think how to test them.

----

To solve this, I am thinking of going through the arrays first, then exhausting the generators in a loop and putting them in an array. This way, we can see how generators can be used to produce values on demand and how they can be iterated over.
