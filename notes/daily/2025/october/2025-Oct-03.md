# Daily Note - October 3, 2025

## Issues from Previous Notes

**Lyre syntax refinement** - The core challenge is making Lyre syntax look and feel more musical. Current syntax with `sequence`, `parallel`, and `tone` is too verbose and implementation-focused rather than expressing musical ideas naturally. A potential solution is preprocessing code with comma expressions to expand into sequence forms, similar to Lisp's quote mechanism. Visual structure can be improved by splitting note sequences with `|` (treated as whitespace).

**Slide design issues** - Several visual issues with slides: background color doesn't extend to full page, next/prev buttons are too big and stuck together, slide is too narrow, inadequate gap between header and content.

- Bold text with both `**text**` and `__text__` syntax

- Bullet points with proper indentation (added `ml-8` for visual tab spacing)
- Horizontal rules for `----` (4+ dashes)
- Clickable links with `[text](url)` syntax, styled with indigo color and hover effects

The slide system now properly renders rich markdown content and presents a coherent path for building the musical language from scratch.
