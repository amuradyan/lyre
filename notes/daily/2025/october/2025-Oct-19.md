## On JavaScript sound testing infrastructure

Solved the problem of testing and hearing JavaScript generator functions that produce audio samples by creating a dedicated component that streams audio in real-time using an `AudioWorklet` processor.

The implementation uses the same streaming architecture as the Lyre codeblock but evaluates raw JS instead. Such code blocks are tagged in slide markdowns with `<!-- playable -->` marker to enable interactive audio code blocks in slides.
