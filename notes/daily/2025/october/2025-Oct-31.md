## On streaming architecture with metadata tuples

Redesigned the audio engine architecture around streaming with metadata tuples. Generators now yield `[sample, n, totalSamples]` instead of bare numbers. This carries timing context without buffering or pre-computation, keeping everything streaming for browser performance.

Sources (oscillator, tone, sequence) generate audio with timing metadata. Transforms (envelope, filter) read that metadata to make real-time shaping decisions. Pure passthrough composition - combinators like sequence don't compute totals or modify metadata, they just chain generators.

Key insight: sources carry timing, transforms shape using that timing. Everything composes naturally because metadata flows through the pipeline.
