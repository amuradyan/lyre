## On tabbed code blocks

Consecutive code blocks now group into tabs automatically. Each tab can import from others using `const {tone} = toneModule` syntax. The trickiest part was circular dependencies - slide 17 has `toneModule` importing from `synth` while `synth` imports from `toneModule`. Fixed by defining all modules first, then adding imports.

Play buttons appear on all tabs in a group, and code edits persist across refreshes. The bundler only exports functions, not local variables like `samplingRate`.
