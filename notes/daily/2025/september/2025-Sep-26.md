## On broken sequences of the same define

There is the following issue with sequence and defines. Below is a quick note on what happens.

```lyre
(define c (tone C4 1000))
(define a (tone A4 1000))

; Works, two seconds of C
(sequence (tone C4 1000) (tone C4 1000))
(sequence (tone C4 1000) (tone C4 1000))

; Fails, just one second of C
(sequence c c)

; Works, two seconds, one for C and A
(sequence c a)
```

Are we popping the values from the env when we resolve define?

...

Fixed the issue where `(sequence c c)` with defined variables only played once instead of twice. The problem was that `define` stored consumed generator objects instead of generator functions. When `sequence` called `yield*` on the same generator multiple times, it was already exhausted after first use. This was fixed by storing generator functions to create fresh generators each time.
