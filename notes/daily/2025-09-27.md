## On Tailwind Font Issue

We discovered that font customization wasn't working because the project uses Tailwind CSS v4, which completely changed how configuration works. The old JavaScript config file approach was being ignored entirely. We switched to the new CSS-based theme configuration and successfully updated the fonts to smoother alternatives (Inter and JetBrains Mono).

This fixed both custom fonts and restored full Tailwind functionality. We should review other recent changes to see what else might have been affected by version upgrades.

## On Index Page Redesign

Restructured the Index page into a cleaner three-section layout: a title section with the Lyre logo and subtitle, a horizontal language reference section explaining syntax and notation, and a two-column bottom section with the code editor on the left and function reference on the right. This organization better separates content types and improves usability.

The new structure also integrated the official Lyre logo from the assets, replacing the emoji placeholder and giving the page a more professional appearance while maintaining the educational focus.
