# Daily Note - September 24, 2025

## On the Engine with Yields

Most of the shvi (SLIm) implementation was salvaged and ported to the browser, with only the core evaluation engine being rewritten using JavaScript generators. The new engine yields audio samples progressively rather than building everything in memory, enabling proper streaming synthesis.

The AudioEngine integrates with Lyre through a clean separation of concerns:
- Lyre evaluator generates raw audio sample arrays using `yield*` for streaming
- AudioWorklet processor handles real-time playback of the generated samples
- Browser Web Audio API manages the audio pipeline and hardware output
- The `run()` function bridges Lyre expressions to playable audio data

This architecture allows Lyre programs to generate audio in real-time while maintaining the original language semantics from shvi.
