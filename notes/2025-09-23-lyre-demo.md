# Interactive Lyre Demo
<!-- slide-id: lyre-demo-2025-09-23 -->

Welcome to the interactive Lyre musical programming language! Here you can write Lyre expressions and hear them played immediately.

## Basic Tone

Try playing a single note:

```lyre
(tone C4 500)
```

## Harmonic Combination

Play multiple notes at the same time with `parallel`:

```lyre
(parallel (tone C4 200) (tone B4 200) (tone A4 400))
```

## Sequential Notes

Play notes one after another with `sequence`:

```lyre
(sequence (tone C4 200) (tone D4 200) (tone E4 200))
```

## Repetition

Repeat a musical phrase with `repeat`:

```lyre
(repeat 3 (tone G4 200))
```

## Complex Compositions

Combine different operations to create richer music:

```lyre
(sequence 
  (parallel (tone C4 300) (tone E4 300))
  (parallel (tone D4 300) (tone F4 300))
  (parallel (tone E4 600) (tone G4 600)))
```

Edit any of the code blocks above and click "Run Lyre" to hear your changes!
