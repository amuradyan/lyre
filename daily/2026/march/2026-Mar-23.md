## On `let` with multiple body expressions

In FP, `let` evaluates all body expressions but returns only the last - all except the last one are there for side effects. But Lyre has no side effects; everything produces sound. Discarding body expressions means losing music, so `let` now sequences all body expressions instead of returning only the last.
