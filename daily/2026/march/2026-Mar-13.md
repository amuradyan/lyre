# On dot notation

I'd like to do one more thing - the `.` notation. I'd like to be able to make `(envelope 0.01 1.0 0 0.01 0 (tone G4))` become `:G4`. From the looks of it it can be considered a special character that would wap the A4 in (envelope a d s r dot-count * gate-time (tone A4)). The problem is I also want to have it as a variable name for the tick in seconds. that would mean it can come up as a name to be resolved or redefines as well as a tone notation, like so:

```
(let
  (. 1)
  -(.C4 .E4 :G4))
```

I assume we can check if a token starts with a . and is not only . we can fix this. then we just expand the ones that start with a dot.
