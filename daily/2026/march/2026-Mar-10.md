The a, d, s and r are the same in all cases and only the gate time changes for the last note. Maybe we can move them up and encode the gate times with dots? If we define them in our code and use it in the envelope, we can do this.

```lyre

(set! decay 0)

(set! release 0)

  (envelope attack decay sustain release 0.5 (tone C4))

  (envelope attack decay sustain release 0.5 (tone G4))
  (envelope attack decay sustain release 0.5 (tone G4))

  (envelope attack decay sustain release 1.0 (tone G4)))
```

Now here's the trick. We can make it so that `.C4` becomes `(envelope attack decay sustain release 0.5 (tone C4))` by pure string manipulation. We just have to agree that the env should have the four names and the tick time - `.`, to compute the actual gate time. If we do that, the code below becomes

```lyre
(set! . 0.5)
(set! attack 0)

```
