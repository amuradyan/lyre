## On the use form

Modules and patches are the same thing - a patch self-exports under its own name. Importing is one atomic form with module name leading, plus one sugar for the common case.

**Atomic form:**

```lisp
(use bass-rack for bassoon cello) ; use the bass rack for bassoon and cello
(use overlay for overlay)         ; bring the overlay callable in
```

**Sugar:**

```lisp
(use overmagnify)                  ; (use overmagnify for overmagnify)
```

Single keyword `use`. Module name always leads. The patch self-exports under its own name, so "import the module callable" is just another instance of the atomic form rather than a separate shape.

A full example:

```lisp
(patch shakuhachi-wah-wah
  (use wah-wah)           ; bring in the wah-wah patch
  (use ww for shakuhachi) ; from woodwinds get the shakuhachi

  (wah-wah 1000 500 1.5 (shakuhachi 440)))
```

Reads top-to-bottom with module name at the start of every line - no jumping back to find the source.
