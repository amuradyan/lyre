# Daily Note - September 29, 2025

## Issues from Previous Notes

The core challenge is making Lyre syntax look and feel more musical. Current syntax with `sequence`, `parallel`, and `tone` is too verbose and implementation-focused rather than expressing musical ideas naturally. We need a macro system to enable syntax sugar for compact time notation (`.A4`, `:A4`, `.:A4`) and more musical terminology like `harmony` instead of `parallel`. This all points toward designing macros that can transform musical notation into the underlying implementation primitives.
