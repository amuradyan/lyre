# 2025-Oct-30

## On refactoring tone into envelope

Created slides on tone refactoring, expressing architectural evolution from monolithic tone function to proper separation: oscillator generates waveform, ADSR computes amplitude envelope, envelope combines them. The tone function became a convenience wrapper with default ADSR.

Key insight: oscillator + ADSR together define an instrument's voice. Moving from stateless `computeSample(frequency, time)` to stateful `function* oscillator(frequency)` that maintains phase internally.

## On Lyre architecture divergence

The Lyre implementation in the slides (slides 22-27) now has cleaner architecture than the one in `/audio.js/`. The slides version properly separates oscillator (stateful phase tracking), ADSR (amplitude envelope computation), and envelope (composition layer). The project Lyre should be refactored to match this architecture - currently it has everything mixed into tone.
