# A musical lisp

Interactive JavaScript learning platform built with React and Deno.

## Useful commands

To run the react development server, use:

```bash
npm run dev
```

To run the static site generator, use:

```bash
deno static/server.js
```

If `npm install` fails, you may need to do:

```bash
npm cache clean --force
rm -rf node_modules package-lock.json
```
