# Harmonics
<!-- slide-id: f1b8bca3-5b32-46a1-9522-19a6885d37d9 -->
<!-- tags: synth, harmonics, overtones, physics -->

Weren't we plucking a string tuned to vibrate at a given frequency?

Well, yes - but when you pluck a real string, it doesn't just vibrate at one frequency. The string vibrates in multiple modes at once - the full length, half length, quarter length, and so on. Each mode produces a frequency that's an octave higher than the previous one. These are called _harmonics_ or _overtones_.

Look at the spectrum - see those peaks? The first is around 233Hz /the fundamental A♯3/, then 466Hz /one octave up/, then 932Hz /two octaves up/, and so on. Each one is roughly double the previous frequency.
