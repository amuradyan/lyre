# ... no gain
<!-- slide-id: a08be0a3-65e6-40c0-b140-6ad59135f6b4 -->
<!-- tags: gain, amplitude, volume, mixing -->

In sound gain is another word for volume adjustment. To handle the volume we need to think of two things *a)* how do we adjust it in the synth and *b)* how we introduce it in the language.

We wrap each `tone` in a `gain`, which takes a second parameter - the amplitude multiplier between 0 and 1:

```lyre
(harmony
  (envelope (gain (tone 237) 0.26) 0.01 0 1 1 0)
  (envelope (gain (tone 473) 0.08) 0.01 0 1 1 0)
  (envelope (gain (tone 926) 0.17) 0.01 0 1 1 0)
  (envelope (gain (tone 1873) 0.20) 0.01 0 1 1 0)
  (envelope (gain (tone 4220) 0.14) 0.01 0 1 1 0)
  (envelope (gain (tone 9646) 0.15) 0.01 0 1 1 0))
```

To the JS implementation then - we need to add a `gain` generator function that takes a source and a gain value, and yields samples multiplied by that gain.
