## On tabbed code blocks

Consecutive code blocks now group into tabs automatically. Each tab can import from others using `const {tone} = sound` syntax. The trickiest part was circular dependencies - slide 17 has `sound` importing from `synth` while `synth` imports from `sound`. Fixed by defining all modules first, then adding imports.

Play buttons appear on all tabs in a group, and code edits persist across refreshes. The bundler only exports functions, not local variables like `samplingRate`.

## On slide organization

Split the slides into two chapters: "Off we go" for fundamentals (0-12) and "Musings in sound synthesis" for the audio stuff (13-21). The navigator now groups them with collapsible sections that auto-expand to your current slide. Crossing between chapters works smoothly with relative links.
